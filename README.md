# Ecommerce Project

Full-stack ecommerce application using React, Node.js, Express.js, and MySQL.

## Tech Stack

- **Frontend**: React + Vite
- **Backend**: Node.js + Express.js
- **Database**: MySQL
- **State Management**: Redux / Context API
- **Styling**: CSS / Tailwind CSS / Material-UI

## Project Structure

```
ecommecer-project/
├── frontend/          # React application
├── backend/           # Express.js server
├── docs/              # Documentation
└── README.md
```

## Getting Started

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```
